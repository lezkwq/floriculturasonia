# Floricultura Sônia

Site institucional da Floricultura Sônia, em Joinville, Santa Catarina. Apresenta buquês, cestas, presentes e coroas de flores, com contato pelo WhatsApp e informações para visitar a loja.

## Desenvolvimento

Requer Node.js e npm.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

As fotos em `src/assets/` são os arquivos originais fornecidos para este site.
